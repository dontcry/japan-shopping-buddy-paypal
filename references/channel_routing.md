# 渠道路由决策树

> 泛化到全品类，判定三问：① 一手新品还是二手/拍卖？② 平台有无公开 API 可自动比价？③ 能否直邮中国大陆（决定直邮 / 转运 / 代拍）？

```
用户丢来日本商品
│
├─ 【一手新品 · B2C 综合商城】（有公开 API，可自动比价）
│   ├─ 乐天市场 ── RWS API 比价 → 需转运
│   ├─ Amazon.co.jp ── PA-API 比价（❌ 已放弃）→ 代拍中转 / 页面快照兜底
│   └─ Yahoo! Shopping ── API v3 比价（❌ 已放弃）→ 可用时启用 / 需转运 / 代购
│       └─ 家电数码锚点：ヨドバシ / ビックカメラ（行货价基准）
│
├─ 【二手 / 拍卖 · C2C】（无公开 API → 走代拍中转取价）
│   ├─ Mercari / Rakuma / PayPay フリマ ── Buyee / ZenMarket / FromJapan
│   └─ 雅虎拍卖（成交价=硬数据）/ Mbok ── 同上
│
├─ 【中古 / 垂直专门】（无 API，按品类直邮或转运）
│   ├─ 手办&动漫中古：骏河屋（国际站直邮）/ Mandarake（直邮）
│   ├─ 手办新品直邮基准：AmiAmi / Hobby Search
│   ├─ 书&音像中古：BOOKOFF（转运）
│   ├─ 服饰：ZOZOTOWN / 2nd Street（代购 / 转运）
│   └─ 家电&乐器中古：HardOff（转运）
│
└─ 【送达 / 支付兜底】任意 URL 粘贴 ZenMarket / Buyee 代拍 + 转运 → 再试算到手价
```

## 路由决策优先级（全品类）

1. **有 API 的一手商城**：**乐天（唯一保证的一手 API）**，优先自动比价（结构化价 + 库存）；Yahoo! Shopping 因无日本手机号放弃、Amazon.co.jp 因联盟 180 天 3 单门槛放弃，两者均降级为「可用时启用」或代拍中转 / 页面快照兜底。
2. **无 API 的二手/拍卖**：Mercari / 雅虎拍卖走代拍中转（ZenMarket ¥300/件 + 免费合箱，Buyee 覆盖最广）取挂卖价/成交价。
3. **垂直直邮平台**（手办/模型）：骏河屋国际站、Mandarake、AmiAmi、Hobby Search 作「直邮到手价基准」。
4. **长尾品类**（书/服饰/家电中古）：按品类触发再查，默认转运。
5. **跨境直邮补充**：Qoo10 Japan（eBay 日本，美妆/低价时尚见长，部分商品跨境直邮）作低价补充渠道。

> **手办/娃娃品类实例**（azone 实战沉淀）：楽天官店（限定预约）→ AmiAmi（常规新品直邮）→ ZenMarket（限定/中古捡漏）→ Mandarake（中古现货）。

> 平台边界：Temu 日本版（中国低价出海、非日本本土商品）、NETSEA/SuperDelivery（B2B 批发）不纳入比价路由。

## 敏感品前置检查（禁运/限运）

**在算到手价之前先判断品类**。以下品类多数转运渠道限制或拒收，必须先向用户提示风险，**不得直接给出"可到手 ¥X"的结论**：

| 品类 | 典型商品 | 处理 |
|---|---|---|
| 液体/膏体（化妆品、香水、酒） | 化粧水、ローション、香水、日本酒 | 多数转运渠道限运；建议改走支持液体的专线或放弃 |
| 电池/含锂电 | 充电宝、无线耳机（含锂电池）、电动工具 | 需申报；部分渠道仅限内置电池小容量 |
| 喷雾/压力罐 | スプレー、エアゾール | 航空禁运，海运周期长 |
| 食品/保健品 | 食品、サプリ、薬品 | 需检疫/准入，多数拒收 |
| 刀具/仿制品 | 包丁、ブランド仿品 | 管制或侵权风险 |

> 判定口径：**识别到即提示**，不解释为"不能买"，而是"这条渠道可能运不了，请先确认转运商对敏感品的收寄规则"。
> 实战例：资生堂 オイデルミン 化妆水（¥9,350）试算到手 ¥550~607，但液体属性使多数渠道拒收——只报价格不报限制就是误导。
