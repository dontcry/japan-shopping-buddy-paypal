# 到手价试算公式

## 公式

```
到手价(CNY) = [商品价(JPY, 含税) + 日本国内运费(JPY)] × 汇率(JPY→CNY)
             + 转运国际运费(CNY) + 转运手续费(CNY) + 合箱费(CNY, 可选)
             + 关税(CNY) + 代购手续费(仅代拍渠道)
```

实现见 `scripts/arrival_price.py`，各分项口径：

| 分项 | 口径 |
|---|---|
| 商品价 | 含税价 × 汇率 |
| 日本国内运费 | 默认 0（乐天同店配送，待实测；可 `--domestic-jpy` 指定） |
| 转运国际运费 | 按线路折算 CNY（见 forwarding_rates.md） |
| 转运手续费 | ¥300~550/件 × 汇率 |
| 关税 | 商品价(CNY) × 品类行邮税率；应征税额 ≤50 元免征（见下节） |
| 代购手续费 | 仅代拍渠道（ZenMarket/Buyee ¥300/件） |

## 关税（中国大陆·个人行邮）

**按《中华人民共和国进境物品进口税税率表》三档税目取值，不是一刀切 20%**（`scripts/arrival_price.py --tariff-category <key>`）：

| 税目 | 品类 key | 覆盖 | 税率 |
|---|---|---|---|
| 1 | `it` | 书报/教育影视、计算机/手机/数码相机等信息技术产品 | 13% |
| 1 | `food` | 食品、饮料、药品 | 13% |
| 1 | `precious_metal` | 金银及其制品 | 13% |
| 1 | `furniture` | 家具 | 13% |
| 1 | `toy` | 玩具、游戏品、节日或其他娱乐用品 | 13% |
| 1 | `sports` | 运动用品（不含高尔夫球及球具）、钓鱼用品 | 13% |
| 2 | `textile` | 纺织品及其制成品（服装/鞋帽/箱包） | 20% |
| 2 | `appliance` | 电视摄像机及其他电器用具（家电） | 20% |
| 2 | `bike` | 自行车 | 20% |
| 2 | `other` | 税目 1/3 未包含的其他商品（普通化妆品、洗护等） | 20% |
| 3 | `tobacco_alcohol` | 烟、酒 | 50% |
| 3 | `jewelry` | 贵重首饰及珠宝玉石 | 50% |
| 3 | `golf` | 高尔夫球及球具 | 50% |
| 3 | `luxury` | 高档手表、高档化妆品 | 50% |

- 完税价格：理论上由海关《完税价格表》确定，实际价格与表列价相差过大时另行核定；脚本按成交价估算。
- **应征税额 ≤ 50 元免征，> 50 元全额征收**（仅适用个人邮递物品）：脚本输出 `tariff.exempt` / `tariff.raw_cny` / `tariff.charged_cny`，免征时确认单显示「应征 X ≤ 50 元，免征」。
- **单次限值 1000 元（港澳台 800 元）**：商品价折算超 1000 元时脚本追加 `postal_limit` 警告——不能直接按个人邮寄清关，需拆单/退运，或转跨境电商零售进口（单次 5000 元、综合税率约 9.1%）/ 按货物报关。
- 实战差异：¥980,000 相机按税目 2（20%）算税 ¥8,284、合计 ¥49,808；按 `it` 13% 只有 ¥5,381、合计 ¥46,882（**差约 ¥2,900**），但该单已远超 1000 元限值，税额仅作参考。¥3,520 万年笔应征 19.3 元 → 免征。

## 试算示例（LYCEE POD020-LYB，¥16,500 含税，EMS）

| 分项 | 计算 | 金额（CNY） |
|---|---|---|
| 商品价 | 16,500 × 0.04224 | 696.96 |
| 日本国内运费 | 默认 0（待实测） | 0 |
| 转运 EMS | 2,200~2,800 × 0.04224 | 92.9 ~ 118.3 |
| 转运手续费 | 300~550 × 0.04224 | 12.7 ~ 23.2 |
| 关税（toy 13%） | 696.96 × 13% | 90.6 |
| **到手价（估）** | — | **约 900 ~ 930 元** |

> ⚠️ 全部金额标注「估算」，试算快照带时间戳；确认前强制刷新汇率与转运价目。
