# 到手价试算公式

## 公式

```
到手价(CNY) = [商品价(JPY, 含税) + 日本国内运费(JPY)] × 汇率(JPY→CNY)
             + 转运国际运费(CNY) + 转运手续费(CNY) + 合箱费(CNY, 可选)
             + 关税(CNY) + 代购手续费(仅代拍渠道)
```

实现见 `scripts/arrival_price.py`，各分项口径：

| 分项 | 口径 |
|---|---|
| 商品价 | 含税价 × 汇率 |
| 日本国内运费 | 默认 0（乐天同店配送，待实测；可 `--domestic-jpy` 指定） |
| 转运国际运费 | 按线路折算 CNY（见 forwarding_rates.md） |
| 转运手续费 | ¥300~550/件 × 汇率 |
| 关税 | 商品价(CNY) × 品类行邮税率；应征税额 ≤50 元免征（见下节） |
| 代购手续费 | 仅代拍渠道（ZenMarket/Buyee ¥300/件） |

## 关税（中国大陆·个人行邮）

**按品类分档，不是一刀切 20%**（`scripts/arrival_price.py --tariff-category <key>`）：

| 品类 key | 覆盖 | 税率 |
|---|---|---|
| `digital` | 数码/相机/手机/电脑/图书 | 13% |
| `toy` | 玩具/游戏品/节日用品 | 13% |
| `apparel` | 服装/鞋靴/箱包/纺织品 | 20% |
| `care` | 化妆品/洗护/香氛（普通） | 20% |
| `appliance` | 家电/家具/体育用品 | 20% |
| `luxury` | 高档化妆品/贵重首饰 | 50% |
| `tobacco_alcohol` | 烟/酒 | 50% |

- 完税价格 = 商品成交价（不含国际运费）；未指定品类时按兜底 20% 估算，并在确认单标注「未指定品类（兜底）」。
- **应征税额 ≤ 50 元免征，> 50 元全额征收**：脚本输出 `tariff.exempt` / `tariff.raw_cny` / `tariff.charged_cny`，免征时确认单显示「应征 X ≤ 50 元，免征」。
- 单次限值 1000 元（港澳台 800 元），超限需退运或按货物申报。
- 实战差异：¥980,000 相机按 20% 算税 ¥8,284、合计 ¥49,808；按 13% 只有 ¥5,381、合计 ¥46,882（**差约 ¥2,900**）。¥3,520 万年笔应征 19.3 元 → 免征。

## 试算示例（LYCEE POD020-LYB，¥16,500 含税，EMS）

| 分项 | 计算 | 金额（CNY） |
|---|---|---|
| 商品价 | 16,500 × 0.04224 | 696.96 |
| 日本国内运费 | 默认 0（待实测） | 0 |
| 转运 EMS | 2,200~2,800 × 0.04224 | 92.9 ~ 118.3 |
| 转运手续费 | 300~550 × 0.04224 | 12.7 ~ 23.2 |
| 关税（toy 13%） | 696.96 × 13% | 90.6 |
| **到手价（估）** | — | **约 900 ~ 930 元** |

> ⚠️ 全部金额标注「估算」，试算快照带时间戳；确认前强制刷新汇率与转运价目。
